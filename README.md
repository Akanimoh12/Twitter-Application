# 🐦 Twitter Application - Modern Social Media Platform

[![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A modern, responsive Twitter clone built with React and Vite, featuring a sleek dark theme interface and comprehensive social media functionality. This application demonstrates advanced frontend development skills with a focus on user experience and modern web technologies.

## ✨ Features

- 🌙 **Dark Theme Interface** - Sleek, modern Twitter-like design
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- 🧭 **Dynamic Navigation** - Smooth routing between different sections
- 👤 **User Profiles** - Complete profile management with bio, followers, and posts
- 💬 **Messaging System** - Real-time messaging interface
- 🔔 **Notifications** - Stay updated with the latest activities
- 🔍 **Search & Explore** - Discover trending topics and new content
- ⭐ **Premium Features** - Premium subscription interface
- 🤖 **Grok Integration** - AI-powered features
- 👥 **Communities** - Community engagement features
- 💼 **Business Tools** - Professional account features

## 🚀 Tech Stack

- **Frontend Framework:** React 18.3.1
- **Build Tool:** Vite 6.0.5
- **Styling:** Tailwind CSS 4.0.0
- **Routing:** React Router DOM 7.1.3
- **Icons:** React Icons 5.4.0 & Heroicons 2.2.0
- **Development:** ESLint for code quality
- **Deployment:** Vercel ready

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Akanimoh12/Twitter-Application.git
   cd Twitter-Application
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   ```
   Navigate to http://localhost:5173
   ```

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint code analysis

The application is built with mobile-first principles:

- **Mobile (< 640px):** Optimized bottom navigation
- **Tablet (640px - 1024px):** Collapsible sidebar
- **Desktop (> 1024px):** Full sidebar with labels
